レシピ分量変換 説明書

「何人前」と書いてあるレシピの材料を、作りたい人数に合わせて一括で換算するアプリです。アプリ本体へ

基本の使い方

  1. 「元のレシピ」が何人前かと、「作りたい」人数を入力します。倍率が大きく表示されます
  2. レシピサイトの材料欄をコピーして貼り付け、「分解して取り込む」を押します
  3. 材料が1行ずつに分かれます。間違いはその場で直せます
  4. 人数を変えると、変換後の分量がその場で変わります。「変換後をコピー」や「買い物メモでコピー」で持ち出せます

貼り付けで取り込める書き方

書き方読み方
鶏むね肉 200g鶏むね肉 / 200 / g
しょうゆ 大さじ2しょうゆ / 2 / 大さじ
玉ねぎ 1/2個玉ねぎ / 0.5 / 個
砂糖 小さじ1と1/2砂糖 / 1.5 / 小さじ
鶏肉200g（スペースなし）鶏肉 / 200 / g
鶏肉 ２００ｇ（全角）鶏肉 / 200 / g
玉ねぎ 半分 / 卵 1個半0.5 / 1.5 として読みます
鶏むね肉 1枚（約250g）括弧の中は備考として残ります（備考の数字は変換されません）

数量が読み取れなかった行は消えずに「数量が読み取れませんでした」と表示され、結果やコピーにも「（要確認）」付きで残ります。数字のない行は見出しとして扱います。

丸め方（作りやすく丸める）

単位丸め方
g・ml・cc10未満は0.5刻み、10〜99は1刻み、100以上は5刻み、1000以上は10刻み。丸めた場合は換算値も併記します
大さじ・小さじ・カップ1/4、1/3、1/2、2/3、3/4 の分数で表示します（例: 大さじ1と1/3）
個・本・枚など0.25刻みで、小数で表示します（例: 1.5個）。0にはなりません
kg・L小数第2位まで。1未満のときは g・ml の目安も添えます

同人数（倍率1）のときは丸めず、元の分量をそのまま出します。丸めずに小数第2位まで見たいときは「きっちり計算」に切り替えてください（分数併記は大さじ・小さじ・カップだけです）。

カップは日本の計量カップ（1カップ＝200ml）が前提です。海外のレシピ（1カップ約240ml）とは違うので注意してください。

変換しないもの

少々、ひとつまみ、適量、お好みで は、何倍にしても「そのまま」と表示します。塩 少々を3倍にしても意味がないためです。

「2〜3人前」のようなレシピ

範囲で書かれたレシピには対応していません。元の人数には代表値（普通は小さい方の数字）を入れてください。材料の「2〜3個」のような範囲表記も読み取れない行になります。

保存について

入力中の内容と履歴は、この端末のブラウザの中にだけ保存します。外部へ送信しません。履歴は20件までです。

iPhoneでは、ホーム画面に追加しておくと長く保存が残ります。ホーム画面に追加せずに長期間（目安は1週間ほど）使わないと、ブラウザの仕組みで保存が消えることがあります。大事なレシピはコピーしてメモなどにも残してください。

ホーム画面への追加: Safariでアプリを開き、共有ボタンから「ホーム画面に追加」を選びます。

注意

  • 変換は目安です。味付けは元のレシピと味見で調整してください
  • 材料ごとの重さ換算（小麦粉 大さじ1＝約9gなど）は材料で値が違うため、このアプリでは扱っていません
