# レシピ分量変換

「何人前」と書いてあるレシピの材料を、設定した人数に換算するWebアプリです。

- アプリ: https://hanaphoto.github.io/recipe-scaler/
- 説明書: https://hanaphoto.github.io/recipe-scaler/manual.html

## 使い方

1. 元のレシピの人数と、作りたい人数を入力する（倍率が表示されます）
2. レシピの材料欄をコピーして貼り付け、「分解して取り込む」を押す
3. 人数を変えると変換後の分量がその場で変わる。「変換後をコピー」「買い物メモでコピー」で持ち出せる

## 特徴

- 貼り付け分解: `鶏むね肉 200g`、`しょうゆ 大さじ2`、`玉ねぎ 1/2個`、`砂糖 小さじ1と1/2`、全角、スペースなし、備考つき（`1枚（約250g）`）に対応
- 丸め: 単なる掛け算で出る「大さじ1.3333」のような数字にせず、大さじ・小さじ・カップは分数で、g・mlは作りやすい刻みで表示。丸める前の換算値も併記。同人数（1倍）のときは丸めない
- 変換しないもの: 少々・ひとつまみ・適量・お好みでは「そのまま」。見出し行と読み取れない行は消さずに残す
- 内部計算は有理数（分数）で行い、1/3や2/3の判定に誤差が出ないようにしている
- 入力は端末内だけで処理し、外部送信なし。オフラインでも動く（PWA）
- 保存は localStorage（入力中の内容は自動保存、履歴は名前付きで20件まで）

## 注意

- カップは日本の計量カップ（1カップ＝200ml）前提です
- 変換は目安です。材料ごとの重さ換算（粉類の大さじ→g等）は扱っていません
